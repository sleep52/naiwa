# 奶蛙小游戏

一个单文件网页小游戏，双击 `index.html` 就能玩，不需要安装任何东西、不联网、没有任何依赖。

## 怎么玩

六种模式，共用一个角色、一个钱袋：

| 模式 | 玩法 | 操作 |
| --- | --- | --- |
| **大肚子弹跳** | 把肚子当弹簧，蹬过三关（村口 / 后山 / 小卖部门口） | 按住 `空格` 或鼠标蓄力，松手弹出去，`←` `→` 决定弹向 |
| **万物皆可吃** | 接住掉下来的好吃的，别接减肥餐 | `←` `→` 或拖鼠标 |
| **喷火大作战** | 蓄火喷出去击退小怪 | `A` `D` 跑，`W` 跳，按住 `J` 或鼠标蓄火 |
| **奶蛙小卖部** | 招呼排队客人、把货扔对，别让他等太久；小心混进来偷货的小偷 | 点货架选货（或 `1`–`5`），点客人把货扔过去；`空格` 招呼最前面那位，`R` 叫货车补货 |
| **舌头矿工** | 奶蛙版黄金矿工：甩舌头抓地下的值钱货，越沉拉得越慢，限时凑够目标额 | `空格` / `↓` / `J` 或点一下 甩舌头，舌头左右摆，抓中会自动往回拉；抓到炸药桶会炸开周围 |
| **养一只奶蛙** | 桌宠，戳肚子听 duang，没有输赢 | 鼠标随便点，`F` 喂食 |

`ESC` 回菜单，`M` 静音。

## 钱袋

六个模式赚的钱都进同一个钱袋（`¥`，屏幕正上方），存在浏览器的 `localStorage` 里，关掉页面还在：

- 弹跳、接食物、喷火按成绩给钱；矿工挖到的东西直接卖钱，小卖部用这些钱进货、扩货架、装修。
- 小卖部每天收摊后有升级面板，装修能让客人更有耐心、还给小费。
- 矿工挖来的烤串会进奶蛙的饭盆，养蛙模式用 `F` 花 ¥15 买粮。
- 矿工每层的矿点分布按当天日期生成，同一天里关卡一样，第二天换一批。

## 目录

- `index.html` —— 完整游戏，自包含（角色贴图以 base64 内嵌）。
- `_build/index.src.html` —— 真正的源码，改代码改这里。里面有个 `__SPR_B64__` 占位符。
- `_build/inject.js` —— 把贴图注入占位符，生成 `index.html`。
- `_build/build-sprite.js` —— 从参考图生成角色贴图的离线流程（抠图、遮背景、擦五官、纯 Node 编解码 PNG）。
- `_build/wa_face.png` —— 生成 `index.html` 用的角色贴图。
- `_build/pull.js` —— 开发时把浏览器里截的 base64 画面存成图片用，跟游戏本身无关。

改完源码重新生成：

```bash
node _build/inject.js
```

音效、挤压形变、粒子这些全是代码实时生成的，没有用任何素材文件。
